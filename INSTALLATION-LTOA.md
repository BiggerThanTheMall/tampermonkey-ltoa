## Vérification des versions

Inventaire contrôlé sur les fichiers des branches `main` des 22 scripts, le 14 octobre 2026. Les 5 écarts de version précédents ont été corrigés. Comparez les versions indiquées à `@version` dans Tampermonkey avant toute installation ou mise à jour.

## Important

- Pour un collaborateur déjà équipé, ne réinstallez que les scripts dont la version installée est inférieure à celle affichée ici.
- Pour un nouveau poste, cette page sert de point d'entrée unique.
- Les scripts conservent leurs propres `@updateURL` et `@downloadURL` afin que les mises à jour futures soient automatiques.
